\section*{Answers to Task 2 Questions}

\textbf{Question 1:} 

Random Network Distillation (RND) uses curiosity-driven exploration by using two neural networks: a fixed \textit{target} network and a trainable \textit{predictor} network. The predictor tries to mimic the target's output for observed states. The key intuition is that states the agent visits frequently become easier to predict (low error), while novel states yield high prediction errors. This error directly serves as an intrinsic reward signal, encouraging the agent to explore unfamiliar states.

\textbf{Question 2:} 

Combining intrinsic and extrinsic returns balances exploration and exploitation. Extrinsic rewards are sparse and task-specific but demands optimal behavior once discovered. Intrinsic rewards provide dense, exploration-focused signals that help overcome sparse reward problems. Merging them in the PPO loss allows the agent to explore effectively early on using intrinsic motivation and Gradually shift focus to task-specific rewards as they're discovered and Maintains exploration even after finding initial rewards to avoid local optima.

\textbf{Question 3:} 

Increasing \texttt{predictor\_proportion} (masking more features in RND loss) hurts learning. Higher masking reduces the predictor's input information, making state prediction harder and Creates noisy intrinsic rewards that misguide exploration.

\textbf{Question 4:} 

Setting \texttt{int\_adv\_coeff=0} (disabling intrinsic motivation) should result int slower exploration, especially in sparse-reward environments and causes Failure to discover complex reward pathways in MiniGrid and converges to suboptimal policies.

As you can see in the below figure, the intrinsic reward decreases if we set \texttt{int\_adv\_coeff=0} but the extrinsic reward maintains it's value with a little noise.
