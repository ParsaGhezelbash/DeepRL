\subsubsection{Experiments}
After implementing the basic \textbf{Dyna-Q} algorithm, run some experiments and answer the following questions:
\begin{itemize} 
    \item How does increasing the number of planning steps affect the overall learning process? 

    \textbf{Answer:}
    Increasing the number of planning steps allows the agent to simulate more transitions using its internal model without interacting with the environment. This generally accelerates learning by reinforcing known experiences and propagating value updates faster throughout the state space.
    
    \item What would happen if we trained on the slippery version of the environment, assuming we \textbf{didn't} change the \textit{deterministic} nature of our algorithm? 

    \textbf{Answer:}
    
    If we use a deterministic Dyna-Q algorithm in a stochastic environment, the learned model will likely be inaccurate, since it only memorizes the first observed transition for each $(s, a)$ pair. As a result, the agent’s planning will reinforce incorrect assumptions about the environment.

    \item Does planning even help for this specific environment? How so? (Hint: analyze the reward signal) 

    \textbf{Answer:}
    
    Yes, planning helps significantly in the deterministic Frozen Lake environment. Since the environment is predictable, once the agent experiences a transition, it can confidently simulate it multiple times through planning. This leads to faster value propagation and reduces the number of real environment steps required to learn an optimal policy. However, if the reward signal is sparse, planning has limited benefit until the agent has experienced a successful episode at least once.

    \item Assuming it takes $N_1$ episodes to reach the goal for the first time, and from then it takes $N_2$ episodes to reach the goal for the second time, explain how the number of planning steps $n$ affects $N_1$ and $N_2$.

    \textbf{Answer:}

    The number of planning steps $n$ has little to no impact on $N_1$, because before the first successful episode, the agent has not yet experienced any meaningful reward. However, $n$ significantly affects $N_2$: once the agent reaches the goal once and experiences a positive reward, a higher $n$ allows this reward to propagate more effectively to other relevant states. As a result, $N_2$ decreases rapidly with higher $n$ values.

\end{itemize}

\subsubsection{Improvement Strategies}
Explain how each of these methods might help us with solving this environment:
\begin{itemize} 
    \item Adding a baseline to the Q-values. 

    \textbf{Answer:}
    
    A baseline can stabilize learning by centering value updates around a reference point. This may reduce variance in updates and encourage better credit assignment, especially in environments with sparse rewards.


    \item Changing the value of $\varepsilon$ over time or using a policy other than the $\varepsilon$-greedy policy. 

    \textbf{Answer:}
    
    Reducing $\varepsilon$ over time allows the agent to explore more in the early stages and exploit its knowledge later. More sophisticated policies can make more informed decisions, balancing exploration and exploitation based on Q-values rather than fixed randomness.
    
    \item Changing the number of planning steps $n$ over time. 

    \textbf{Answer:}
    
    Starting with a small $n$ can prevent overfitting to an initially inaccurate model, while increasing $n$ as the model becomes more accurate allows for better planning and faster convergence. This adaptive approach can yield more stable and efficient learning.

    \item Modifying the reward function. 

    \textbf{Answer:}
    
    Reward shaping can guide the agent toward more promising behaviors. For example, assigning small penalties for stepping on frozen tiles or bonuses for reaching intermediate states could accelerate learning and improve exploration. However, shaping must be done carefully to avoid altering the optimal policy.

    \item Altering the planning function to prioritize some state–action pairs over others. (Hint: explain how \textbf{Prioritized Sweeping} helps) 

    \textbf{Ansewr:}

    Prioritized Sweeping improves planning efficiency by focusing updates on state–action pairs that are most likely to impact the value function significantly. This avoids spending planning steps on irrelevant or already learned transitions and allows the agent to converge faster with fewer planning updates.

\end{itemize}
