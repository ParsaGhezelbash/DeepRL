# Deep Reinforcement Learning Coursework

This repository is a curated portfolio of my Deep Reinforcement Learning (DRL) coursework. It includes end‑to‑end assignments, clean implementations, runnable notebooks, and compiled reports spanning foundational to advanced RL topics.

## Repository Structure

-   `HW/`: Homework folders (`HW 1` to `HW 14`) containing:
    -   Assignment questions (`.pdf`)
    -   Solution notebooks (`.ipynb`)
    -   LaTeX reports and generated PDFs (when applicable)
    -   Project code for select assignments
-   `Direct Preference Optimization/`: A mini‑project on Direct Preference Optimization (DPO) with poster and presentation.
-   `RL RoadMap/`: A concise learning path and concept map for RL (`RL-Map.md`).
